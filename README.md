# 公倍数ステップ

小学校5年生向けの算数学習Webアプリ「公倍数ステップ」です。
教科書で学習する「2つの数の公倍数は、最小公倍数の倍数になっている」という性質を体感的に学習できるゲームです。

## 🌐 サイトURL
[https://yukileno.github.io/koubaisuu-step/](https://yukileno.github.io/koubaisuu-step/)

## 🔧 教師（管理者）用設定手順

このアプリは、ランキング情報をGoogleスプレッドシートに保存するためにGoogle Apps Script (GAS) をバックエンドとして使用します。
以下の手順でご自身のGoogleアカウント環境にバックエンドをセットアップしてください。

### 1. スプレッドシートの準備
1. Googleドライブで新しいスプレッドシートを作成します。
2. シート名を `Ranking` （先頭大文字）に変更します。
3. 1行目に以下のヘッダーを設定します：
   - A1: `Timestamp`
   - B1: `Name`
   - C1: `Score`
   - D1: `Token`
4. スプレッドシートのURLからID（`https://docs.google.com/spreadsheets/d/【ここの文字列】/edit`）をコピーしておきます。

### 2. GASのセットアップ
1. スプレッドシートのメニューから「拡張機能」＞「Apps Script」を選択します。
2. 開いたエディタの `コード.gs` に、本リポジトリ内の `Code.gs` の内容をすべてコピー＆ペーストして保存します。
3. エディタ左側の歯車アイコン（プロジェクトの設定）を開きます。
4. 「スクリプト プロパティ」までスクロールし、「スクリプト プロパティを追加」をクリックします。
5. プロパティ名に `SPREADSHEET_ID`、値に先ほどコピーしたスプレッドシートのIDを入力して保存します。

### 3. Webアプリとしてデプロイ
1. エディタ右上の「デプロイ」＞「新しいデプロイ」をクリックします。
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選択します。
3. 以下の設定にします：
   - 実行するユーザー: `自分`
   - アクセスできるユーザー: `全員`
4. 「デプロイ」をクリックします（初回はアクセス承認が求められますので許可してください）。
5. 完了後に表示される **ウェブアプリのURL** をコピーします。

### 4. アプリ側へのURL設定
このリポジトリをFork（またはダウンロードして編集）し、`api.js` の1行目にある `GAS_URL` に、コピーしたWebアプリのURLを貼り付けてください。また、`USE_MOCK = false;` に変更してコミット＆プッシュすることで、本番環境と連携します。

## 🎮 教師用のカスタマイズ方法

### 問題や制限時間の変更
- **制限時間の変更**: `main.js` の `let state = { timeLeft: 90, ... }` の数値を変更してください。
- **問題の変更**: `main.js` の `questions` 配列の中身を変更してください。
  例: `{ a: 2, b: 3, lcm: 6 }`

### ランキングのリセット・非表示
- **リセット**: スプレッドシートの `Ranking` シートを開き、2行目以降のデータをすべて削除してください。
- **非表示**: `index.html` から `<button id="btn-ranking-view">` と リザルト画面のランキング登録エリアを削除してください。

## ⚠️ 制約・リスク
- **完全な不正防止の限界**:
  ゲームのスコアはブラウザ側のJavaScriptで計算してGASへ送信しています。通信内容を改ざんされるリスクを減らすため、セッショントークンを発行して重複送信を防ぎ、スコアの範囲チェック等を行っていますが、技術に詳しいユーザーが悪意を持って意図的に偽のスコアを直接送信することを完全に防ぐことはできません。あくまで「クラス内での楽しく競い合うツール」としてご活用ください。
